# Personal portfolio

This is the repository behind my personal portfolio at salmaahmed.dev.

I built the site to keep my university work, technical projects and experience in one place while I finish my Software Engineering with Electronics degree at the University of Westminster.

The portfolio includes work across software, data analysis and embedded systems. I wanted the site to feel personal rather than like a standard developer template, while still being straightforward for someone looking through my work.

## Projects featured

The site currently includes MasonBee, my Formula 1 machine learning analysis and embedded systems work from my degree. I will keep adding to it during my final year, including my final-year project as it develops.

## About the repository

Alongside the website files, this repository contains some of the supporting material used on the portfolio, including project reports and analysis files. Some of these will eventually move into their own repositories so the technical work is easier to explore on GitHub.
